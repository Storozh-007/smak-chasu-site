# Смак часу

Сайт ресторану «Смак часу» — адаптивна презентаційна сторінка гастрономічного простору в Києві.

## Можливості

- Адаптивна верстка для мобільних пристроїв і комп’ютерів.
- Перемикання ранкового, денного та вечірнього настрою.
- Інтерактивна книга меню та галерея інтер’єру.
- Демонстраційне оформлення замовлення з розрахунком суми, чайових і поділом рахунку.
- Створення PDF-рахунку на пристрої відвідувача.
- Локально підключені шрифти та зображення.

## Перегляд

Відкрийте `index.html` у браузері або запустіть локальний сервер із кореневої папки проєкту:

```bash
python3 -m http.server 8000
```

Потім перейдіть на <http://localhost:8000>.

## Публікація

Сайт не потребує збірки. Для GitHub Pages достатньо вибрати гілку `main` і папку `/` у налаштуваннях Pages репозиторію.

## Структура проєкту

- `index.html` — розділи сайту та їхній вміст.
- `css/` — стилі та локальні шрифти.
- `js/app.js` — інтерактивність, меню та генерація PDF.
- `js/vendor/` — бібліотеки `jsPDF` і `html2canvas`.
- `assets/img/` — зображення інтер’єру та страв.
- `assets/menu/` — сторінки меню.
- `assets/fonts/` — файли шрифтів.

## Перед використанням

- Замініть демонстраційний номер телефону в `index.html` на актуальний.
- Бронювання зараз демонстраційне: форма не надсилає заявку на сервер.
- Замовлення формується лише на пристрої відвідувача й не передається до ресторану.
- Щоб змінити страви та ціни, відредагуйте масив меню на початку `js/app.js`.
